# Mitra Home website

The public website for Mitra Home, a free, local-first household assistant: bills, papers, dates and reminders for the
whole family, kept on the family's own PC.

Static HTML and CSS, served by GitHub Pages from the `main` branch. No build step, no outside scripts.

The source of these pages lives in the app repository under `site/`; this repository is the published copy.

The name "Mitra Home" and the logo identify the official project.
