Install

Set up Mitra Home in about 15 minutes

Mitra Home lives on one computer at home, the PC or the Mac. The phone apps connect to it over your home Wi-Fi. No typing commands.

Mitra Home is in public beta (version 0.137.0). The Windows installer is signed; the Mac app is signed and notarized by Apple. Downloads are in the steps below. The source code is available on request: Source code.

Download for Windows Mac, Apple silicon Mac, Intel

Choose what to install

Beta Windows PC One installer (.exe). No Python or admin rights needed. Beta Mac A Mac app (.dmg) you drag into Applications. No Python needed. Google Play Android phone The family's companion app: what is due, money, scan papers, tick lists. App Store iPhone The same companion app for iPhone.

Before you start

A home computer

Windows 10 or 11, or a Mac. One that is usually switched on, because it is where reminders are made and phones connect.

Nothing else to install

The Windows installer and the Mac app bring their own copy of Python and everything the app needs. No admin password, no typing commands.

An AI helper (optional)

Helps read messy papers. Use a plan you already have, a cheap key, or a free model on your PC. You can add it later. Which one?

Install on your computer

  1. Download and run the installer

    Download for Windows (.exe, 48 MB)

    Double-click MitraHome-Setup-0.137.0.exe. It installs for you only, so it does not ask for an administrator password, and it brings its own copy of Python. A checkbox lets Mitra Home start by itself when you sign in to the PC (ticked by default).

    The installer is signed (publisher: Rajesh Katukojwala). Windows may still show "Windows protected your PC" because a new installer has little download history. Click More info, then Run anyway. To check the file, compare its SHA-256 with SHA256SUMS.txt.

  2. Pick the family's folder

    The installer suggests Documents\Mitra-Home-Data (or your user folder when Documents syncs to OneDrive). Your family's papers, settings and database live there. Updates and uninstalling never touch it.

  3. Open Mitra Home from the Start menu

    The first start prepares everything (a minute or two), then your web browser opens on the setup page by itself. Keep the small window that opens: closing it stops Mitra Home.

  4. Answer the setup chat

    A short conversation in your browser: your family's name, who lives with you, whether you own or rent, your cars, an AI helper (you can skip it) and a PIN for each adult.

    127.0.0.1:8601/setup
    Who lives in the household? Type everyone, with their role and birthday if you like. Pets are welcome.
    Alex, adult
    Jordan, adult
    Sam, child
    Biscuit, dog
    Do you own or rent your home?

    You can stop any time and come back; it remembers where you were.

  5. Drop in a few papers

    Open Add and drag in a recent bill, a bank statement and your car insurance. Watch them appear on Today and in Family and Money.

  6. Let it run on its own

    At the end of setup, open Settings > Data > Runs on its own and switch them on. This sets up the daily brief, the weekly family digest and the weekly backup.

Installing from the zip instead

  1. Install Python

    Go to python.org/downloads and click the yellow Download Python button. Run the file you downloaded.

    Python setup
    Add python.exe to PATH ← tick this first
    Use admin privileges when installing py.exe
    Install Now

    Important: tick Add python.exe to PATH at the bottom of the first screen, then click Install Now.

  2. Unzip Mitra Home into its own folder

    Save the zip you were sent, right-click it, choose Extract All and pick a simple place, for example D:\MitraHome or Documents\MitraHome.

    Your family's own files will live in a second folder next to it, called Mitra-Home-Data. Updates never touch that folder.

  3. Double-click Start Mitra Home.bat

    A black window opens. The first time, it prepares everything it needs (a few minutes). Then your web browser opens on the setup page by itself.

    Start Mitra Home
    Preparing a private Python environment (one time, about a minute)... Installing what the app needs (one time, a few minutes)... Starting on http://127.0.0.1:8601 ... Mitra Home is running. Keep this window open: closing it stops it.

    If Windows asks whether to run a file you downloaded, choose Run. Keep the black window open; closing it stops Mitra Home. Starting it again simply reopens the same one.

Then continue with the setup chat above.

  1. Download and open the .dmg

    Apple silicon (M1 and newer, 35 MB) Intel Mac (41 MB)

    Not sure which one? Apple menu > About This Mac: "Chip: Apple M…" means Apple silicon; "Processor: Intel" means Intel. To check a file, compare its SHA-256 with SHA256SUMS.txt.

  2. Drag Mitra Home onto Applications

    The window that opens shows the app and an Applications folder. Drag one onto the other, then eject the disk.

  3. Open it the first time

    Double-click Mitra Home in Applications. The app is signed (developer: CLOUDWARE EDGE LLC) and notarized by Apple, so macOS only asks once whether you want to open an app downloaded from the internet: click Open.

    The first start prepares everything (a minute or two, no internet needed), then your browser opens on the setup page. Mitra Home runs in the background with no Dock icon; double-click it again any time to reopen the browser.

  4. Answer the setup chat

    Same as on Windows: family, people, home, cars, an optional AI helper, and a PIN for each adult. Your family's files live in Documents/Mitra-Home-Data; updates never touch that folder.

  5. Drop in a few papers and let it run on its own

    Use Add, then Settings > Data > Runs on its own. On a Mac these become login items (LaunchAgents), so no extra permission is needed.

Installing from the zip instead

  1. Install Python

    Go to python.org/downloads, download the macOS installer and run it (version 3.12 or newer).

  2. Unzip Mitra Home into its own folder

    Double-click the zip you were sent and move the folder somewhere simple, for example your home folder: ~/MitraHome.

  3. Open Start Mitra Home.command

    The first time only: right-click it and choose Open; if macOS still refuses, use Open Anyway under System Settings > Privacy & Security. Keep the Terminal window open while you use Mitra Home.

Then continue with the setup chat above.

The Mac app is newer than the Windows installer and tested less. Linux is not tested yet.

Install the phone apps

The companion app shows what is due and the month's money, scans papers into the inbox, ticks off lists, adds events and reminders, and can alert you before an appointment. Phones talk only to your PC or Mac, over your home Wi-Fi, with an encrypted link. Nothing goes through the internet.

Android

Free on Google Play.

iPhone

Free on the App Store.

  1. Give each adult a PIN

    The setup asks for this. Phones are refused until at least one PIN exists. Once one does, Mitra Home is open to your home Wi-Fi every time it starts, with nothing extra to run.

  2. Pair the phone

    On the PC open Settings > Phones > Add a phone. A QR code appears for 5 minutes. Get the app from Google Play or the App Store, open it and scan the code.

    Without the app: open the address shown in Settings > Phones (like https://192.168.1.20:8701) in the phone's browser, check the fingerprint matches, sign in with your PIN and choose "Add to Home Screen".

  3. Phone cannot connect?

    Open Settings > Phones > Connection on the PC. It shows whether Windows Firewall lets phones in and whether your Wi-Fi is set to Private. Press Allow phones through Windows Firewall (Windows asks you to confirm; it opens only the phone port, on private networks only). If you started the app "this PC only", press Restart for phones.

Set up a family wall

An old tablet becomes the family's screen in the kitchen or hall: the week in each person's colour, what is on today, the children's jobs with stars, the family lists, the meals, and a big clock (or your photos) when nobody is using it. It works only on your home Wi-Fi, with an encrypted link, and the PC has to be on.

  1. Choose the tablet

    An iPad, an Android tablet or a Fire tablet. An iPad uses the browser wall. On Android and Fire tablets you can use the browser too, or the Mitra Home app in wall mode (it keeps working from its own copy when the PC is off).

  2. Make a wall code

    On the PC open Settings > Phones > Mitra Wall, give the wall a name (for example Kitchen wall) and press Show the wall code. The code works once, for 15 minutes. Up to five walls can be paired.

  3. Pair it

    Browser wall: point the tablet's camera at the code, or open the address under it and type the eight letters and digits. The first time the browser warns the connection is not private, because the certificate is your PC's own. Continue only when its fingerprint matches the one on the PC, then press Pair this wall.

    App wall (Android and Fire): install the app, then on the first screen scan the wall's QR code. If the tablet cannot scan (some Fire tablets have no scanner), use Can't scan?, paste the text from the PC's Copy the text button, or type address:port CODE fingerprint.

    A tablet is either a wall or a person's phone, not both. To change it, use Forget this phone in the app and pair again.

  4. Keep it on the wall

    Plug the tablet in. iPad: Auto-Lock to Never, then Guided Access with a passcode so it stays on the wall. Android: the longest screen timeout, and App pinning. Fire: the longest screen timeout, on its charger.

  5. Set it up (optional)

    On the PC, Family > Routines adds the children's jobs, stars, goals and rewards. Settings > Phones > Mitra Wall > Wall screen chooses the clock face, the photos (several at once; the PC strips their location first) and the night hours. Money opens on the wall only when an adult types their own PIN, and locks again after a minute.

  6. Tablet cannot connect?

    Same checks as for phones: Settings > Phones > Connection, then Allow phones through Windows Firewall or Restart for phones. The wall guide in the app's docs/MITRA_WALL.md lists every message and its fix.

Updating

Open Settings > Data and press Check for updates. Your database is backed up first, and your family's files are never replaced. Every release is signed and checked before it is installed.

Health check

Settings > Data > Health check lists anything that needs attention (backups, AI helper, scheduled tasks) and how to fix it.

Leaving

Settings > Data > Export all my data writes every table as spreadsheet files. Your original papers are already plain files in the archive folder.

If something goes wrong

"Python was not found" or the black window closes at once

Install Python 3.12 or newer from python.org and make sure Add python.exe to PATH is ticked. If you already installed it without that box, run the installer again, choose Modify, and tick it. Then double-click the starter again.

The browser did not open

Open your browser yourself and go to http://127.0.0.1:8601. If another program uses that port, Mitra Home picks the next free one (8602 to 8610) and prints it in the black window.

The phone shows a certificate warning

That is expected the first time: the certificate belongs to your own PC. Continue only if the fingerprint shown matches the one in Settings > Phones on the PC.

A document is still waiting on Add

When Mitra Home is not sure what a paper is, it asks you instead of guessing. Open Add: each waiting file says why, and Why? shows what was tried. Press File it, check the type, vendor and date, and it is filed; or Try again after turning photo reading on.

Need help?

Describe what you saw without personal details (no account numbers, no names), and include the message from Settings > Data > Health check. We never ask for access to your data.
