Written offer of source code

The installers offered on the Install page are built from the source code of the same version number.

Download the source of version 0.130.3 (zip, 2 MB)

Until the source is published in a public repository, we will also send you the complete corresponding source code of any version we distribute, on request:

  • How to ask: email cloudwareedge@gmail.com with the version you downloaded (for example 0.130.3). Anyone who has a copy of the program may ask; you do not need to give a reason.
  • What you get: the source of that version as a downloadable archive, together with the scripts we use to build the installers (the 0.130.3 download above is exactly that).
  • Cost: none for a download link or an email attachment. If you want a physical medium, only the cost of the medium and sending it.
  • When: within 14 days of your request.
  • For how long: for each version, at least three years after we last offered that version for download here.

Public repository

We plan to publish the source in a public repository once testing with our first families is complete. When we do, this page will link to it, and the written offer above will still apply to the versions already released.
