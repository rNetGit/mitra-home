Recommended: an OpenRouter key ($5 lasts most families a year)

Without an AI, bank statements, phone bills, PayPal statements and school calendars are still read on this PC. Other papers (bills, policies, receipts, statement layouts it does not know) wait in the Inbox for you, and Chat cannot answer questions.

  • Only for what needs it. The AI reads just the papers this PC cannot read by itself, and Chat questions.
  • Private first. Names and account, policy and ID numbers are masked before anything is sent (the last four digits stay). Photos are sent only if you tick that box below.
  • Not used for training. It is a paid key under your own account, and Mitra Home asks OpenRouter to use only hosts that neither keep nor train on what is sent. Free AI tiers (such as Gemini's free API) can use what you send for training: use a paid key.
  • Cost. About 60 cents a month for a busy family (40 papers and 60 Chat questions), less for most. $5 of credit lasts most families a year or more.
  1. Sign up at openrouter.ai.
  2. Add $5 of credit in Credits (OpenRouter adds a card fee of $0.80). Leave auto top-up off: when the credit is used up the AI simply pauses, and you are never charged more.
  3. In Keys, create a key named Mitra Home and set its credit limit (for example $2 a month). Copy the key: it is shown only once.
  4. Check that training stays off in Privacy.
  5. Here: Provider OpenRouter, paste the key, tick the box, press Save. Leave Model blank for the default.

Not now? Everything else works; add a key any time in Settings > Connections.

What each choice costs and does
  • Claude Code (your own Claude login): Best for statements. Runs only when you open Claude Code.
  • Google Gemini (API key, paid tier): About $0.40 a month for a family. Use a key with billing enabled. Default model: gemini-2.5-flash.
  • OpenAI (API key): About $0.20 a month: the cheapest hosted option. Default model: gpt-4o-mini.
  • Anthropic Claude (API key): About $1 a month for a family. Default model: claude-haiku-4-5-20251001.
  • OpenRouter (one API key, many models; recommended): About 20 to 60 cents a month for a family ($5 of credit lasts most families a year); any model, default google/gemini-2.5-flash. Only hosts that neither keep nor train on prompts are used. Default model: google/gemini-2.5-flash.
  • Your Claude plan (the Claude Code you signed in to): No extra cost on a Claude Pro / Max plan. Inbox filing and Chat; text only, so no photos. Install Claude Code from Anthropic and sign in yourself first. Default model: haiku.
  • Ollama (a model on this PC): Free, nothing leaves this PC, lower accuracy. Default model: llama3.1.
  • No AI: Files wait for you; digests and the dashboard still work.

Bank sync (SimpleFIN) Not set up

Optional, for power users: balances and new transactions pulled every morning through SimpleFIN Bridge (a service the family pays about $1.50 a month). Statements in the Inbox work without it.

SimpleFIN Bridge (bridge.simplefin.org) is a paid service the family signs up for themselves (about $1.50 a month, paid to them, not to Mitra Home). You connect your banks there; Mitra Home only asks it, read-only, for balances and new transactions once a morning. Nothing else leaves this PC. Make a setup token there and paste it here. docs/BANK_SYNC.md has the steps.

Mail folder off

Any mail provider, not just Gmail: make a new mailbox only for Mitra Home, forward bills, statements, school letters and receipts to it (or set a forwarding rule in your main mail), and Mitra Home copies what arrives into the inbox, read-only. Use an app password from that provider's security settings, never the account's own password. docs/MAIL_FOLDER.md has the steps for Gmail, iCloud, Outlook.com and Yahoo.

Read-only: messages stay unread and nothing is moved or deleted. Attachments pass the same checks as any upload; a message without one is kept as text. The app password stays on this PC.

Other calendars 0 added

An iCloud, Outlook, school or work calendar shown on the Calendar page next to everything else, read-only. In that calendar, copy its subscribe or publish address (it ends in .ics or starts with webcal://).

The address stays on this PC and goes only to that calendar's own server, read about once an hour. Titles and times are kept; descriptions and places are not. Nothing is written back.
